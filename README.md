# 佳利达 · 报销事项助手

Edge 本地扩展，版本 **0.2.9**。仅支持差旅费报销单（流程 230）、业务招待报销单（流程 231）和日常费用报销单（流程 232）。在当前报销页面显示可收起悬浮窗，点击「新建费用事项」后读取发票，直接覆盖填写费用事项。完成后可将原页面首行的公共字段复制到其余事项，再查看待补项和逐票日志。

## 安装与更新

1. 打开 `edge://extensions`，启用开发人员模式。
2. 点击「加载解压缩的扩展」，选择本项目的 **extension 文件夹**，不要选择项目根目录或 ZIP。
3. 将「佳利达 · 报销事项助手」固定到工具栏。
4. 已安装旧版时，在扩展卡片上点击「重新加载」，确认版本为 0.2.9；回报销页面刷新后再点击插件。

无需构建或安装依赖。扩展出现在管理页但工具栏没有图标时，在 Edge 扩展菜单中将其显示到工具栏。

## 使用

1. 在原系统打开差旅费、业务招待或日常费用报销单，填好基本信息和发票。其他类型的报销单暂不支持。
2. 点击工具栏插件图标，当前页面右侧出现悬浮窗，不跳转独立操作页。
3. 点击 **新建费用事项**，自动读取、计算、覆盖填写。执行期间显示进度，可收起悬浮窗。
4. 在原报销页首条费用事项选择公共字段，然后点击悬浮窗的「应用首行到所有」。助手在点击时读取系统已选的值，复制到其余事项；首行空白字段不会覆盖其他行。差旅单复制费用部门、费用小类、成本中心、出发城市、到达城市；日常费用单复制费用部门、费用小类、成本中心；业务招待单复制费用部门、成本中心。
5. 查看仍需补齐或跳过的项目；展开或下载日志。
6. 核对后自行保存、提交。插件不会保存或提交。

点击插件只打开助手；点击新建费用事项才修改表单。执行期间不要修改来源发票、切换报销单或刷新页面。

## 三种报销单的运行逻辑

以下规则对应当前扩展版本。助手读取当前表格的**全部发票行**，删除勾选不影响计算范围；按每张发票的价税合计汇总报销金额，可抵扣税额按对应单据的规则填写。三种单据之间不共用「普票是否可抵扣」等特殊规则。

### 差旅费报销单（流程 230）

1. **识别和分组**：按发票内容识别交通、住宿、餐费、其他；汽油、柴油、停车、过路、ETC、租车、代驾、出行服务等属于交通。再按「分类 + 交通用途（打车、火车、燃油、机票等）+ 发票属性 + 费用事项税率」汇总。城市不参与分组。内容同时命中多个分类且无法确定时，跳过该发票并记录原因。
2. **票种和抵扣**：普通普票填「普票 / 0%」，不抵扣；专票按票面税率和票面税额抵扣。电子普通发票的内容含「客运服务费」且票面税率为 3%，或明确是滴滴电子打车票时，填「电子打车票」并按票面税额抵扣。铁路电子客票填「火车票」，选择票面税率对应的「计算抵扣」选项，使用发票信息中的票面税额。普通机票及对应航空旅客保险归入「机票」，抵扣为 0。
3. **出差补助和行程**：有有效发票且基本信息中的出差天数为正整数时，另建一条不关联发票的「其他费用 / 其他 / 0%」补助事项，金额为天数 × 60 元，税额为 0。城市优先从事前申请费用说明中的「上海到深圳」等行程提取；若没有明确行程而原费用事项的城市一致，则沿用原值。城市或天数无法确定时，已明确的发票分类与金额仍填写，缺失字段列为待补；天数无效时不生成补助。
4. **写入字段**：自动选择费用小类「国内差旅费」，填写费用明细、发票属性、税率、报销金额、税额及可确定的城市和天数。费用部门、成本中心保留原匹配行的值；也可在原页填好首行五项公共字段后应用到其余事项。

### 业务招待报销单（流程 231）

1. **识别和分组**：普通发票只按内容分为「餐饮」和「非餐饮」两组；同组普票即使票面税率不同也合并。专票按内容识别出的交通、住宿、餐费、其他类别，再按票面税率分组；例如住宿专票与其他服务专票即使税率相同也分开。同一类别、票种和税率的发票汇总为一条事项；内容同时命中多个类别时跳过该发票并提示核对。
2. **票种和抵扣**：本单所有普通发票均填「普票 / 0%」、可抵扣税额 0，包括 3%「客运服务费」电子普通发票；不会沿用差旅单的电子打车票抵扣规则。专票填「专票」、票面税率和票面税额，金额为价税合计。
3. **写入字段**：只自动填写发票属性、税率、报销金额、税额。该表没有差旅单的费用明细、城市、天数和出差补助字段。费用部门、成本中心可在原页首行选好，再应用到其余事项。

参考案例的 120 张发票按上述规则形成 6 条事项，报销金额 73,723.03 元、可抵扣税额 194.90 元。其中两张合计 74.60 元的 3% 客运服务费电子普票并入非餐饮普票，可抵扣税额为 0。

### 日常费用报销单（流程 232）

1. **费用用途**：按发票内容识别员工福利、团建等为「薪酬福利 / 福利费」，办公用品、装订、打印、快递等为「日常费用 / 日常办公费」。费用大类是整单字段：全部内容能一致判断时自动选择；同时出现不同大类或有内容无法判断时，不自动选大类，列为待补。若页面已经选了「薪酬福利」，无法从内容判断用途的发票会沿用「福利费」；若已选「日常费用」，仍不会猜测费用小类。
2. **分组和抵扣**：按费用小类、发票属性和费用事项税率汇总。相同小类的普通发票无论票面内容、税率如何，都合成「普票 / 0%」，税额为 0；不同小类分别汇总。专票与普票分开，单一税率的专票按票面税率归集，抵扣票面税额。无法判断小类的发票仍可按明确的票种、金额生成事项，小类留空并列为待补。
3. **多税率专票**：当前版本不能从发票表取得并核实逐项金额和税额；遇到一张专票含多个票面税率时，跳过该发票并提示人工拆分，不按总额猜测。其他有效发票继续生成事项。
4. **附件金额**：页面「附件发票金额」为正数时，将其并入「普票 / 0%」，不抵扣。附件没有逐票信息，日志明确标记「票种未核实」，需要人工核对。若附件金额无效或为负数，则停止自动写入。原费用事项金额与全部发票及附件金额不一致时，日志提示差额；计算仍以有效来源金额为准。
5. **写入字段**：自动选择可确定的费用大类、小类，填写发票属性、税率、报销金额和税额。不填写城市、天数或差旅补助。之后可从原页首行复制费用部门、费用小类和成本中心；此手动操作会以首行小类覆盖其他事项原先按发票内容生成的小类，应在保存前核对。

薪酬福利案例中，11 张表格发票合计 1,084.47 元，附件发票金额 1,526.66 元并入普票 / 0%，合计 2,611.13 元，附件票种仍须人工核对。日常办公案例中，4 张普票合计 721.69 元可生成普票事项；另有一张 89.00 元、含 6% 和 13% 的专票会被跳过并提示人工拆分。原费用事项合计 811.69 元，比全部表格发票 810.69 元多 1.00 元，日志会列出差额。

### 三种单据共同的异常与覆盖规则

- 缺少发票号码或内容、票种或金额无法识别、价税合计与票面税额及未税金额不一致时，跳过该发票；重复号码的全部同号发票也跳过。其余有效发票继续计算。系统缺少所需的发票属性或税率选项时，跳过对应分组并记录原因。
- 点击「新建费用事项」直接按本次有效分组覆盖费用事项，无独立预览或二次确认；再次点击会重新读取并计算。匹配的旧事项保留费用部门和成本中心。未匹配旧行若已有这两个字段，则清空旧费用字段、保留公共字段并提示核对；否则删除旧行，避免旧金额重复计入。分组写入失败时清理该组的部分写入；清理失败则停止并提示人工核对。
- 没有任何可生成的分组时，不覆盖原费用事项。填写完成后在日志查看每个事项包含的发票、跳过原因和待补字段；插件不替用户保存或提交。

## 应用首行公共字段

先在原系统的首条有效费用事项中选好公共字段，再点击悬浮窗「应用首行到所有」。点击时直接读取该行 `WfForm` 中已选的系统值和显示名称，复制到其余有费用分类或金额的事项；无需在助手里重复搜索动态选项。首行未填写的字段不复制，目标行原值保留并列入待补。差旅单可复制费用部门、费用小类、成本中心、出发城市和到达城市；日常费用单复制费用部门、费用小类、成本中心；业务招待单复制费用部门、成本中心。日常费用单使用此按钮会覆盖其他事项按发票内容生成的费用小类，请在保存前逐项核对。

此操作也可用于已有费用事项，无需重新生成。助手会核对当前报销单；单个字段复制失败时尝试恢复该字段原值，继续处理其余字段并提示核对。不会修改发票、费用明细、票种、税率、金额或税额，也不会保存、提交。

## 日志、权限与适配

展开日志首先显示「费用事项与发票核算表」：按原表费用事项行号列出该事项全部发票号码、内容、价税合计、票面税率、票面税额和可抵扣税额，表尾显示事项合计及费用事项未税金额。出差补助单独列出天数、每天标准和金额，标明不关联发票。已跳过分组单独标记未填入，不混作已填写事项。下载文字日志也包含同样的核算表。

日志含北京时间、逐票发票号、内容、分类、票种、金额、税额、汇总、操作结果、跳过原因和待补字段。本机保留最近20次，可下载带 UTF-8 BOM 的文本。

只申请 `activeTab`、`scripting`、`storage`。不上传发票，不调用外部服务，不保存账号密码。悬浮扩展窗通过扩展运行时调用适配器，不接受网站消息作为填写指令。

仅支持 `crm.jd-link.com:8888` 的差旅费报销流程 230、业务招待报销流程 231 和日常费用报销流程 232。使用系统 `WfForm` 接口，不猜内部选项代码，不删除来源发票。员工差旅报销单暂未接入。
