# 佳利达 · 报销事项助手

Edge 本地扩展，版本 **0.2.5**。在当前报销页面显示可收起悬浮窗，点击「新建费用事项」后读取全部发票，直接覆盖填写费用事项。完成后可批量填写费用部门、成本中心及出发、到达城市，再查看待补项和逐票日志。

## 安装与更新

1. 打开 `edge://extensions`，启用开发人员模式。
2. 点击「加载解压缩的扩展」，选择本项目的 **extension 文件夹**，不要选择项目根目录或 ZIP。
3. 将「佳利达 · 报销事项助手」固定到工具栏。
4. 已安装旧版时，在扩展卡片上点击「重新加载」，确认版本为 0.2.5；回报销页面刷新后再点击插件。

无需构建或安装依赖。扩展出现在管理页但工具栏没有图标时，在 Edge 扩展菜单中将其显示到工具栏。

## 使用

1. 在原系统打开差旅费报销单，填好基本信息、发票、事前申请。
2. 点击工具栏插件图标，当前页面右侧出现悬浮窗，不跳转独立操作页。
3. 点击 **新建费用事项**，自动读取、计算、覆盖填写。执行期间显示进度，可收起悬浮窗。
4. 在悬浮窗的「批量填写公共字段」中，为费用部门、成本中心、出发城市、到达城市选择当前网页的候选值，或输入原页面可搜索到的准确名称。点击「应用到所有项」，留空的输入框不会修改对应字段。
5. 查看仍需补齐或跳过的项目；展开或下载日志。
6. 核对后自行保存、提交。插件不会保存或提交。

点击插件只打开助手；点击新建费用事项才修改表单。执行期间不要修改来源发票、切换报销单或刷新页面。

## 自动填写规则

- 读取全部发票行，删除勾选不影响参与计算范围。
- 分类为交通、住宿、餐费、其他。汽油、柴油、停车、过路、ETC 等属于交通。混合类别无法确定时跳过发票。
- 按 **分类 + 费用用途（打车、燃油、机票等）+ 发票属性 + 抵扣税率** 分组；城市不参与分组。燃油与机票即使同为交通费、普票、0%，也分别生成费用事项。
- 金额累加价税合计，票面税额单独记录。普通普票的费用事项税率和可抵扣税额均为 0；专票按票面税率及税额抵扣。
- 电子普通发票的内容含「客运服务费」且票面税率为 3% 时，按「电子打车票」填 3% 并抵扣票面税额。票种或内容明确标识滴滴电子打车票时，也按该票面税率及税额处理。
- 必要发票信息缺失、票种无法识别、金额不一致时跳过发票。重复号码的全部同号发票均跳过；其余有效发票继续。
- 城市从事前申请费用说明的 `上海到深圳` 格式提取，天数来自基本信息。城市、天数等缺失时仅留空相应字段，明确的分类和金额继续填写。
- 费用小类选择实际选项「国内差旅费」。系统无法匹配的共用字段留空，列入待补项。
- 系统没有所需的发票属性或抵扣税率选项时，跳过整个分组，继续其他分组并在日志中说明。
- 已有事项直接覆盖。按分类、票种、税率、用途匹配旧分组；无法识别旧用途时再按同组金额匹配，保留对应费用部门和成本中心。
- 无法匹配的旧行，有部门或成本中心时清空旧费用字段、保留这两个字段并提示核对；没有这两个字段时删除旧行，避免旧金额重复计入。
- 分组填写失败时清理部分写入并提示。清理也失败则停止，要求人工核对原页。
- 全部发票无效或没有发票时，不覆盖原费用事项。

正常流程无独立预览、无二次确认。再次点击新建费用事项会重新读取并覆盖。

## 批量填写公共字段

悬浮窗从当前费用事项的系统选项和已有选值读取候选名称；聚焦输入框时刷新候选。对于按关键词加载的系统选择器，可输入名称，插件在原页面选择唯一匹配项，不猜内部代码。打开悬浮窗后，即使不重新生成费用事项，也可以给已有事项批量填写。只处理当前报销单中有费用分类或金额的事项；填写前再次校验报销单和事项是否变化。某一项或字段无法匹配时，保留原值、继续其他字段，并列入待补提示。批量填写不会修改发票、金额、分类或税额。

## 日志、权限与适配

展开日志首先显示「费用事项与发票核算表」：按原表费用事项行号列出该事项全部发票号码、内容、价税合计、票面税率、票面税额和可抵扣税额，表尾显示事项合计及费用事项未税金额。已跳过分组单独标记未填入，不混作已填写事项。下载文字日志也包含同样的核算表。

日志含北京时间、逐票发票号、内容、分类、票种、金额、税额、汇总、操作结果、跳过原因和待补字段。本机保留最近20次，可下载带 UTF-8 BOM 的文本。

只申请 `activeTab`、`scripting`、`storage`。不上传发票，不调用外部服务，不保存账号密码。悬浮扩展窗通过扩展运行时调用适配器，不接受网站消息作为填写指令。

支持 `crm.jd-link.com:8888` 差旅报销流程230。使用系统 `WfForm` 接口，不猜内部选项代码，不删除来源发票。
